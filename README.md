# HADES666 — Staff Manager Portfolio

Portafolio profesional para gestión y organización de equipos Staff de servidores Minecraft.

## Archivos
- `index.html` — página pública.
- `style.css` — diseño, responsive y animaciones.
- `script.js` — renderizado y efectos.
- `config.js` — contenido editable.
- `admin.html` — panel de administración.
- `admin.js` — lógica del panel.

## Admin
Abre `admin.html`.

Contraseña inicial: `Hades661`

### Publicar cambios
1. Entra al panel.
2. Edita el contenido.
3. Pulsa **GUARDAR**.
4. Pulsa **DESCARGAR CONFIG.JS**.
5. Sube el nuevo `config.js` a GitHub y reemplaza el anterior.
6. GitHub Pages publicará la nueva versión.

> Importante: en GitHub Pages la contraseña del panel es una protección de interfaz, no seguridad de servidor. Al ser una web estática, alguien con conocimientos puede inspeccionar el código. Para seguridad real se necesita autenticación con servidor/backend.
